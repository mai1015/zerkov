# Bunker hideout map

User-authorized scope: replace the temporary bunker map with an authored,
Tarkov-inspired industrial hideout using the supplied Bunker-Assets.zip; run
Godot, provide genuine screenshots, and open a separate PR. No generated
concept image is part of this change.

The new production presentation is a six-area cutaway with native kit sprites,
room inspection and two cosmetic lighting presets. It retains the existing
bunker route's CommonActivatableScreen inheritance and menu owner. Build,
craft, upgrade, persistence, power simulation and gameplay navigation are not
implemented or implied. Existing art/license distribution gates stay in force.

The current exact 1920x1080 output and 640x360 world at 3x are retained. No
smaller-output suite or unrelated raid task is executed or accepted here.
