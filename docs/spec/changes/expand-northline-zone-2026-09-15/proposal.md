# Expand Northline into a connected full-zone environment

User request: "looks good, do we have like the full map? this is kind of small."
The preceding approved direction is a native Godot environment using the
supplied packs, not generated artwork. This change addresses that requested
map-size expansion and provides a full-map overview plus detail captures.

Scope: one 2688x1792 environment, nine connected districts, native collision
inspection, an overview, source-pixel detail views and an updated PR #8.
Existing small studies and the production raid remain unchanged. No AI, combat,
loot, working extraction, settlement, multiplayer or smaller output support.
The user request is not recorded as final visual/gameplay acceptance.
