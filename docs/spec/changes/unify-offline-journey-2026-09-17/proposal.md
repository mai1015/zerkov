# Unify the offline player journey

## Approved scope

The user approved a creative UX/consistency pass on 2026-09-17, after reviewing the bunker and identifying discontinuity with briefing/deployment. Retain the new bunker environment and existing authored workspaces; do not restore fixtures or replace the campaign architecture. Treat Bunker -> Preparation -> Briefing -> Deployment -> Raid -> Committed Results -> Bunker as one journey.

## Changes

Reuse a small shared visual vocabulary for framing, panels, status, buttons and operation context. Bring useful real loadout information into briefing. Preserve the briefing return destination when editing equipment or inspecting health, without changing normal bunker-origin Back behavior. Carry the selected operation into loading and results. Make unavailable information explicit without diagnostic prose dominating the player view. Retain the lean HUD and existing authoritative game owners.

## Non-goals

No addon/engine promotion, multiplayer, economy, crafting/building service, save schema, equipment mechanics, combat tuning, new map integration or responsive redesign. No invented progress percentages, equipment values or reward claims. Changes are branch-only and user-reviewed.
