# Add editable Shoreline visual prototype

## Goal
Bring the approved generated-v2 coastal visual direction into Zerkov as an additive, editable Godot scene: lower-repetition terrain, reusable props, enterable building composition and coherent ground-plane shadows.

## Boundary
This change does not register a production raid map or alter NativeRaidMap preflight, collision authority, persistence, inventory, extraction or AI ownership.
