# Zerkov: two original extraction environment studies

Open `map_studies.tscn` with F6. The production main scene is not changed.
This is a native scene, not an image backdrop: source-art regions, foot-sorted
sprites, authored wall/cover collision shapes, and real light nodes compose it.

**Northline Depot:** customs records, central freight warehouse, workshop,
rail-side loading route, motor pool, and a separate fuel pocket. The road offers
a direct exposed traverse; the rear/customs route is longer and broken up.

**Mercury Block:** supermarket, evacuation clinic, transit offices, a wrecked-bus
crossing, rear alleys, metro stairs, and a courtyard. Medical/supply/intel pockets
are design markers only. Extract activation and loot tables are not implemented.

Controls: WASD or left-drag to pan; Q/E for authored sectors; 1/2 for maps;
Tab or the button to show the proposed route/extraction annotations. This is a
camera walkthrough, not a playable character, live raid or safety assessment.

Edit `maps.json` for placements, buildings, paths and markers. Edit the source
manifest under `assets/world/map_studies/atlas.json` for authored regions and
normalization. The map-study units do not redefine ZWorldUnits.

76 regions from 11 sheets across the two supplied packs are selected, normalized
by nearest 1/3 (48px to 16px), and packed into a shared 256-colour palette atlas.
The atlas is WebP lossless **after** these recorded transformations; it is not
claimed byte-identical to original PNGs. No images were generated by an image
model. No whole source archives, new fonts, engine binaries or unrelated assets
belong in the implementation.

The supplied art remains internal-development/review content. A redistribution
grant is not inferred from receipt of a ZIP; existing distribution blockers stay
in force. This scene has no dependency on the task-9 or bunker PR branches.

## Test

```sh
python3 -m unittest discover -s tests/tooling -p test_map_studies.py -v
python3 tests/tooling/run_map_studies_gate.py --godot "$ZERKOV_GODOT" --output /tmp/map-review-new
```

The native runner pins Godot 4.7.2 and needs a graphical Xvfb/OpenGL environment.
It never substitutes the existing native gameplay addons: they are simply out
of scope for this additive scene. Only the existing exact-capture guard is reused.
